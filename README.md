# Guía de estudio · Certamen 1 FEP

Página estática (un solo `index.html`) para estudiar el Certamen 1 de Formulación de Proyectos Informáticos: plan horario, resumen de Arquitectura de Software, trabajos de investigación, fórmulas, ejercicios resueltos y simulacro de alternativas.

El avance del plan y las respuestas del simulacro se guardan sólo en el navegador de cada persona.

## Publicar con GitHub Pages

1. Crear un repositorio público y subir `index.html` (y este README) a la rama `main`.
2. Settings → Pages → Source: «Deploy from a branch» → rama `main`, carpeta `/ (root)` → Save.
3. En uno o dos minutos queda en `https://<usuario>.github.io/<repositorio>/`.
